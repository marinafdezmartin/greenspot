# Datos GIS pendientes

Esta carpeta está reservada a los GeoJSON reales que entregará la propietaria desde ArcGIS Pro. No hay capas integradas en la fase A.

Fuente prevista: [Datos abiertos del Ayuntamiento de Madrid](https://datos.madrid.es/). Con cada entrega se documentarán el conjunto concreto, URL de origen, licencia, fecha de descarga, cobertura, transformaciones, geometrías, campos y sistema de referencia. Ninguno se presupone ahora.

En fase B se revisará la exportación WGS84 / EPSG:4326, se integrará mediante `GeoJSONLayer` y se validarán los cálculos en metros con ArcGIS Pro. Las coordenadas en grados no se usarán como distancias métricas. No añadir datos de ejemplo.
